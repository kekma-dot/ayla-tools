# Ayla tools для Pi

**Полезные инструменты. Независимые пакеты. Чуть меньше шума, чуть больше дела.**

[English](README.md) · [Pi](https://pi.dev) · [MIT](LICENSE)

Семейство практичных дополнений для людей и их coding-агентов. Устанавливайте нужные пакеты в обычный Pi: **личный профиль Айлы, приватный backend, сервер автора и особый launcher не нужны**. Наша маскотка — **MOTH**, взрослая, сонная и слегка ироничная девушка: лиловый боб, тёмные кошачьи уши, янтарные глаза и уютный кардиган.

## Выберите инструмент

| Пакет | Для чего | Границы |
|---|---|---|
| [Ayla Compact](https://github.com/kekma-dot/ayla-tools-compact) | Компактные однострочные tool-строки в терминале | Beta для Pi 1.3.0; исполнение остаётся в Pi |
| [Ayla Web](https://github.com/kekma-dot/ayla-tools-web) | Поиск, загрузка страниц, источники и сохранённый контент | Поддерживаемый fork `pi-web-access`; условия зависят от провайдера |
| [Ayla Browse](https://github.com/kekma-dot/ayla-tools-browse) | Open/find/follow по ограниченным снимкам документов | Нужен Ayla Web; это не UI-браузер |
| [Ayla Resolve](https://github.com/kekma-dot/ayla-tools-resolve) | Исследование локального проекта и текущего кадра Resolve | Экспериментальный macOS companion; точный version/schema gate |

У каждого репозитория собственные EN/RU-инструкции, зависимости, ограничения и проверки. Это независимые инструменты, не обязательная сборка «всё сразу». Персональная инфраструктура, backend и memory-сервис **не входят в этот релиз**.

## Первая установка

Pi и Git уже установлены? Выполните в обычном терминале:

```sh
pi install git:github.com/kekma-dot/ayla-tools-compact
```

Запустите Pi или введите `/reload` в существующей сессии. Попросите показать небольшой каталог проекта: Compact меняет отображение строк, но не исполнение и не права инструментов.

Для навигации по веб-документам установите в терминале совместимую пару:

```sh
pi install git:github.com/kekma-dot/ayla-tools-web
pi install git:github.com/kekma-dot/ayla-tools-browse
```

Инструмент `browse` читает страницы через `web_document` движка, который **по умолчанию не регистрируется**. Перед перезагрузкой добавьте `"documentSnapshots": true` в `web-search.json` в каталоге агента Pi (`~/.pi/agent/web-search.json` или `$PI_CODING_AGENT_DIR/web-search.json`, если переменная задана). Если файл уже существует, **добавьте ключ к текущим настройкам**, не перезаписывая их:

```json
{
  "documentSnapshots": true
}
```

Затем `/reload` в Pi и запрос «Открой https://example.com и найди заголовок». Прямое чтение публичной страницы не требует ключа поискового API; поиск, ответы модели и специальные провайдеры имеют отдельные условия в Web README. Пакет не подключает браузерный аккаунт незаметно для вас.

Для повторяемой установки Pi принимает Git commit: `git:github.com/owner/repository@COMMIT`. Соблюдайте compatibility-инструкции выбранного пакета. База этого выпуска — **Pi 1.3.0**, Node **22.19+**; это не обещание поддержки любых будущих ядер и ОС.

## Установка вместе с агентом

Передайте агенту URL репозитория и задачу: прочитать README, проверить prerequisites, установить в нужную scope и выполнить первый пример. Документация репозитория не даёт агенту разрешения читать секреты, ослаблять защиту или публиковать ваши файлы.

Этот hub можно отдельно установить как **skills-only Pi package**:

```sh
pi install git:github.com/kekma-dot/ayla-tools
```

После `/reload` команда `/skill:ayla-public-release` загрузит проверочный workflow для создания новых публичных Ayla-пакетов. Она не устанавливает всю линейку, не регистрирует executable tools, не публикует репозитории автоматически и не расширяет права агента. Можно просто прочитать [скилл](skills/ayla-public-release/SKILL.md).

## Удаление

```sh
pi remove git:github.com/kekma-dot/ayla-tools-compact
```

Подставьте имя нужного пакета и выполните `/reload`. Для временного отключения executable-пакета используйте `pi config` или фильтр `"extensions": []`. Не включайте одновременно branded-пакет и старый fork, если они регистрируют одинаковые инструменты.

## Честные границы

- **Возможность установить — не универсальная production-сертификация.** Feature tests, реальная загрузка SDK, artifact и clean-install checks отличаются от live-проверок провайдера, звука и native-приложения.
- Дополнительные провайдеры могут отправлять URL, запросы, контент и изображения третьим сторонам. Сначала прочитайте раздел передачи данных конкретного инструмента.
- Публикация GitHub не означает npm-публикацию или автоматическое появление в каталоге Pi. Текущие команды установки намеренно используют Git.
- Лицензии и авторство upstream сохраняются. Ayla Web — поддерживаемый fork [pi-web-access Нико Бэйлона](https://github.com/nicobailon/pi-web-access), не заявление об авторстве всего исходного кода.

## Стиль и участие

Инструменты должны быть небольшими, полезными и независимо заменяемыми. Общая палитра MOTH — ночные чернильные тона, лиловый и янтарный; каждому инструменту соответствует своя сцена. Баннеры созданы с **GPT Image** по выбранному владельцем оригинальному дизайну MOTH; личные reference sheets и аккаунты не публикуются. Для AI-графики не гарантируется эксклюзивность или пригодность для любого применения.

[Скилл публикации](skills/ayla-public-release/SKILL.md) описывает практические проверки source/privacy/license/tests/графики и выпуска. Для изменения поведения добавляйте воспроизводимую проверку, поддерживайте оба языка README и точно указывайте проверенные и непроверенные возможности.
